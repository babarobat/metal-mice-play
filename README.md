# Metal Mice browser edition

Compiled public game assets. Play at https://babarobat.github.io/metal-mice-play/ .

Open the game on each device while online and choose **Save game for offline**.
Then use the same Wi-Fi/hotspot, create a password-protected room and exchange
an invitation QR and an answer QR. No signaling, STUN or TURN servers are used.
Keep the host game in the foreground; an OS may suspend background apps.
